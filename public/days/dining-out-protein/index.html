Dining Out While on GLP-1

Today's plan in one breath: restaurant portions are typically 2–3× what a GLP-1 user can comfortably eat; strategy is protein-first, take-half-home. The default move is order a starter-sized main and a side of protein (e.g. grilled prawns). A low-energy day is information about the medication working, not a character flaw, and the session simply shrinks to match it.

A plan for the day

  1. Morning. Log energy before deciding anything. If LOW, today's session is already chosen: Low-Energy 20-Minute Session.
  2. Training window. Order a starter-sized main and a side of protein (e.g. grilled prawns)
  3. Food anchor. Protein first, small portion: Cooked Skinless Chicken Breast.
  4. Evening. Hydrate, note one line in the log (energy 1–5, session done yes/no). Two data points beat two hours of worry.

When this is the wrong choice

This playbook is the wrong tool if symptoms escalate: contact a clinician.
